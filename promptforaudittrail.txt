# Correlation ID

The API Gateway already generates and forwards:

```http
X-Correlation-Id
```

The DPS service must:

* Read CorrelationId from request header
* Store it in AuditContext
* Use the same CorrelationId for every audit event

Never generate CorrelationId in DPS.

Only read it.
